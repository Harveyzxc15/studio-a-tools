# 北一區週報評語：本工具專屬規則

**寫法、語氣、選題、用字禁忌一律以使用者的技能 `store-report-style` 為準**
（`~/.claude/skills/store-report-style/` → 連到 `~/.codex/skills/store-report-style/`，同一份檔案）。
寫之前載入該技能，並讀它的 `references/excel-to-store-overview.md`（Excel 轉門市概況流程）。
本檔只補充「這個自動化工具」特有的事項，兩者衝突時以技能為準。

## 讀取順序
1. 技能 `store-report-style`（SKILL.md ＋ excel-to-store-overview.md；需要時搜尋 26q4-examples.md）
2. `評語修改紀錄.md`：使用者把自動初稿改成定稿的紀錄，最近 4 週最重要，照他的修改方向寫
3. `評語範例/` 最近一週＝前週定稿（追蹤與避重複的依據）
4. 本週 `~/工具中心/輸出/北一區週報簡報/<週次>/評語素材.md`（唯一的當期數字來源）

## 輸出格式
同資料夾的 `評語.json`：
```json
{"士林": ["上週店點狀況", "執行進度與改善狀況"], "微風": [...], "美麗華": [...],
 "阿波羅": [...], "高島屋": [...], "羅東": [...]}
```
六店兩格都要有；維修滿意度那一列不用寫（使用者手填）。數字疑點不寫進評語，放在交件通知裡。

## 素材對照（技能的資料定義檢查用）
- 「3PP 搭售／零搭售」表＝EPB 重建的 DSS 3PP 交易層級判定，**可以**用來寫零搭售台數與佔比
  （零搭售 ÷（搭售＋零搭售））；配件件數不可反推零搭售。
- BY店 本週比較 的 ACPP 區塊：`ACPP+搭售率`＝AC+ 單獨；`合計搭售率`＝AC+＋SA Care，要寫「保固合計搭售率」。
- 「上週快照」區塊才有上週的 ARpedia、MySetup；沒有就不要寫「由 X 套增加至 Y 套」。
- 喇叭金額看「喇叭金額（含 Momax）」；各類配件金額看各店「配件 - XX門市」的週對比。
