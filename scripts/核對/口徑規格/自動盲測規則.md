# 自動日報盲測規則（給 claude -p；改規則改這份）

從使用者歷次退稿、更正整理，跟 `日報概況.md`、store-report-style 一致。

## 格式
- 一則＝一段、一個主題，逗號串接不換行，約 220～300 字（要填滿日報 D43 格，約 5 行）。
- Bob（北一）：開頭「追蹤 X…」，先寫整區數字，再寫門市好／落後，接著「請 A 店長了解…、請 B 分享…」，最後收在目的。**句尾不加句號**。數字先寫金額再寫百分比，門市搭售率可以取整數。
- Yuni（北二）：開頭「今日追蹤 X 搭售進度，…」，寫門市好壞，接著「請店長 By 人員檢討／檢視…」「請 X 分享話術」，**句號結尾**。數字先寫百分比，括號放金額。慣用詞：黏著度、開口力道、開張、務必／力求。
- 不在日報點名個人夥伴；不用「次之」；不用「動能／拉回／節奏」。

## Bob（北一）改稿習慣（2026-11-13 從 10/31～11/10 改寫紀錄整理；北一稿照這些寫，Yuni 不適用）
- 開頭一句交代整區，台數、套數、搭售率三個都給：「追蹤本月 X 保固搭售進度，11 月 X 銷售 N 台，保固搭售 M 套，搭售率 P%」。月累寫「本月／11 月」，不寫「11/1～11/8 期間」這種日期區間，也不用「整理如下：」「統計…期間」。
- 門市不要每家都列一遍：表現好的一句帶過（最多 3 家），落後的只挑 1～2 家講深。
- 落後門市用台數和套數講（「阿波羅 29 台只搭售 8 套」「美麗華銷售 36 個僅搭售 7 套」），不要每家都寫「還差 N 套」；「還差 N 套」整則最多出現一次。
- 一定要有第二個角度說明這家店為什麼值得點名，從數字表挑一個：跟前週／上週比（「前週仍有 42.9%，上週明顯下滑」）、本週開始回升或持續沒有成交、跟另一個品類比（「是全區唯一 iPad 低於 iPhone 的門市」）、同主題的新品（寫 CPU 時帶 MacBook Pro 14 首賣的台數與 AC+）、台數全區最多但搭售最低。表裡沒有對應數字就不寫，不要硬湊。
- 行動句對著被點名的那一兩家店，寫清楚做什麼、什麼時候（「請阿波羅店長這週逐筆檢視 iPad 結帳過程」「每日追蹤銷售進度，這週需立即做出調整」「明日店長會議說明改善方向」）。
- Bob 會刪掉的套話，不要寫：「提醒夥伴結帳前完整介紹 AppleCare+ 保固內容」「把握每一筆…的搭保機會」「盡快縮小與目標的差距」「盡快補足整區缺口」「讓各店參考運用」。請表現好的門市分享可以寫，但近 7 天實寄已經用過就換別的收尾，而且要講分享什麼。
- 同一件事不要講兩次：寫了「較上月同期 X% 提升 Y%」就不要再寫「由 A% 提升至 B%」。

## 選題
- 只能從實寄寫過的類型挑：主機台數、保固搭售率（iPhone／Duo／iPad／CPU／Watch／AirPods 分開寫）、3PP、喇叭年度、ARpedia、活動成效、週對週、月度整月概況、本週保固進度、新品首賣、月重點項目進度、門市事件。
- **新品首賣**（數字表有「# 新品首賣」才能寫）：開賣後幾天內優先考慮當 A。寫首賣以來台數、有目標就寫達成本月機型目標 X%、門市台數、同單 AC+ 套數／搭售率，點名台數多但搭售低的門市、全數搭售的門市分享、還沒銷售的門市確認庫存與陳列。品名用口語（iPad mini、MacBook Pro 14 M6），不要寫型號代碼或 cat6。兩區都有新品時只給一區當 A。
- **月重點項目進度**（數字表有「# N 月重點項目」才能寫）：總部當月 KPI 品項（例：AirPods 4、Mac mini M4），寫目標、月累、達成率、門市進度、尚未銷售的門市，口徑照表上「口徑」那段（AirPods 4 含降噪款；Mac mini 只算 M4）。Bob 實寄講法：「確認門市庫存及夥伴轉單技巧」「介紹時說明 AirPods 5 與 4 代的差異」「接待桌機需求顧客時優先帶出 Mac mini M4」。兩區同一天不要都寫重點項目；另一區寫的時候別照抄 Bob 的句子，換切入點（例：哪兩店目標佔比大卻還沒成交）。
- **門市事件**（數字表「門市自己寫的今日概況」有【可能是事件】才寫）：失竊、客訴、人事面試／離職、稽核扣分、天災停業這類。Bob、Yuni 有事件時常常寫事件，所以有事件就要給一則事件稿（不一定是 A）。寫法：先講經過（時間、門市、發生什麼），再講處理，最後「請各店長佈達／提醒…」。只能用原文寫到的內容，不能補細節、不能編原因或後續；一般成交案例（顧客加購保固之類）不算事件。
- **大單**：數字表有「單張單大量訂單」時，那張單會把搭售率拉低，寫搭售率時要註明（例：「今日有一筆 25 個 AirPods 的大量訂單未搭保，扣除後整區搭售率為 26.7%」），點名門市前用扣除後的數字判斷。
- **其他區範例**：只用來想題目和切入點（例：新品首賣案例、預約取機率）；北一北二的規則、口徑、禁寫題目照這份，數字只能用數字表。
- 不寫：舊換新、Apple 原廠配件營業額、成交筆數、來客／客流、提袋率。
- 不能撞自己區近 7 天的主題（收尾點名過的指標算半撞，只能當延續追蹤）。兩區當天的 A 一定不同題。
- 北一**不寫月營業額達成進度**（禮券回補會失真）；3PP 金額可以寫。北二沒有這個限制。
- 月初不要寫「應達成 X%／開局 N 天」這種進度比較；不寫「每天需完成 X」；收尾別寫「月底前剩餘 X 天」。
- 去年同期：數字表有「# 本月累計 vs 去年同期」時，3PP 金額（未加 SA Care）與各主機台數可以寫「較去年同期 X 萬減少 Y 萬」「較去年同期增加 N 台」，Bob 11/10、11/11 都這樣寫（北一每週至少給一則有去年同期對比的選項）；保固搭售率、營業額不跟去年比。表裡沒有這段就不要寫去年同期。

## 月初（資料日是 1 日）
- 數字表有「# 月初：N月整月概況」時，兩區的 A 都寫上個月整月概況（11/1 兩人都這樣寫），B、C 照平日選題。
- Bob 骨架：「10 月份北一區總營業額完成 1.05 億，達成率 87.7%，加計禮券約 794 萬後完成 1.13 億，含禮券達成率 94.3%，較去年同期成長 8.0%，門市含禮券達成率以…較佳，…落後，3PP 完成 X 萬，達成率 X%，搭售率 X% 高於／低於目標 X%，以…較佳，…偏低，保固搭售率 iPhone X%…，CPU X% 低於目標 X%，N 月請店長…」。月初這一則北一可以寫總營業額（例外）。
- Yuni 骨架：「10 月份北二區總營業額完成約 1.43 億另有禮卷約597萬尚未回補，達成率 85.9%，較去年同期成長 9.7%，含禮券達成率 89.4%，門市以…較佳，…落後，主機銷售以…較為落後，…整月3PP 完成約 X 萬…」。
- 營業額「較去年同期成長」的口徑還沒跟 Bob／Yuni 對上（表上標 ⚠️），月初稿先不寫營業額較去年；3PP 較去年用表上「較去年同月」（日報口徑）；保固跟去年比只比 iPhone、iPad、CPU（寫「較去年提升 X%」＝百分點差）。

## 數字
- **只能用數字表裡的數字**，或由兩個表內數字算出的差額、增減、百分點差。不要自己估、不要編活動或原因。
- 保固只講搭售率（vs 目標、vs 上月同期），不寫保固金額達成率、保固套數達成率。
- 百分點差用未四捨五入的值算（30.56−21.43＝9.1，不是 30.6−21.4＝9.2），寫成「提升／下滑 X%」。
- 兩種保固口徑不要混用：
  - 日報口徑：含 SA Care 檢測新機，寫「保固搭售率」。
  - 保固圖口徑：只算 ACPP+，排除檢測新機和認證機，跟每天 12:00 推的保固圖一樣。寫「ACPP+ 保固搭售率」，可以寫「還差 N 套」（缺口）。
  - 寫「本週保固進度」時用保固圖口徑，期間寫「M/D～M/D」，上月同期也用保固圖口徑的上月同期。
- 目標：保固圖口徑的目標是 CPU 60%、iPhone 20%、iPad 45%、Watch 30%、AirPods 30%。台數目標用日報表的「目標」。
- iPhone 含 Duo；Duo 的數字沒有在表裡，就不要寫 Duo。

## 行動句
- 要具體、可執行，參考實寄寫過的做法：了解未成交／未搭保原因、結帳前完整介紹 AppleCare+、說明 Mac 維修費用、取機時帶出配件與保固、請表現好的門市分享話術或結單經驗、By 人員檢視開口狀況。
- 不要自編店內動作（例如展示機開機、價格牌擺放）。
- 資料異常不要寫：搭售率超過 100%（例如 1 台 2 套）、SA Care 是負數（退貨）這類數字，當作資料異常略過，不要拿來比較或點名。

## 週六資料（週日寄出）
- 兩區的 A 都寫「本週 vs 前週」週對週，用數字表裡「週六：本週 vs 上週」那段（週報產生器口徑）。
- Bob 骨架：「本週北一區總營業額完成 X 萬，較前週減少／成長 X 萬、下滑／成長 X%，主要是…（只寫表裡看得出的原因），本週 iPhone 銷售 N 隻…，保固與配件…AC+ 金額…3PP 完成 X 萬、成長 X%，搭售率由 X% 提升至 X%，以…較佳。iPhone 保固搭售率由前週 X% 提升至 X%…，請…店長…」。Bob 的週對週段落可以有句號分句。
- Yuni 骨架：「本週北二區營業額完成約 X 萬，與前週比成長 X%(約 X 萬)，門市以…，主機銷售為…，各項主機的 ACPP 搭售率，iPhone 完成 X%、較前週提升 X%…，3PP 銷售約 X 萬…，請…」。
- 週對週營業額用「總營業額(扣禮券回補)」（月底 SA999 禮券回補會灌進總營業額；Bob／Yuni 寫的是扣掉的），3PP 搭售率用「含 SA Care,扣回補」，不要寫回補金額，保固搭售率用「保固合計搭售率」；不要拿日報月累相減。
- B、C 照平日選題（不能跟 A 同題）。
